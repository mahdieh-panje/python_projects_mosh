# 🐍 Beginner Python Projects

This repository contains a collection of beginner-friendly Python projects I built for training and practice.  
Each project focuses on basic programming concepts such as loops, conditionals, functions, user input, and working with libraries.

---

## 📂 Projects

### 🎲 Dice Rolling Game
- **Description**: Simulates rolling two dice until the user decides to stop.  
- **Concepts used**: `while` loops, conditionals, and the `random` module.  
- **File**: [`dice_rolling_game.py`](dice_rolling_game.py)

---

### 🔢 Number Guessing Game
- **Description**: The computer generates a random number between 1 and 100, and the player tries to guess it.  
- **Features**: Input validation and hints ("Too low", "Too high").  
- **File**: [`number_guessing_game.py`](number_guessing_game.py)

---

### 📱 QR Code Generator
- **Description**: Generates a QR code for any text or URL provided by the user.  
- **Concepts used**: External library (`qrcode`), input handling, and file saving.  
- **File**: [`qr_code_generator.py`](qr_code_generator.py)

---

### ✊🖐️✌ Rock Paper Scissors
- **Description**: Classic Rock-Paper-Scissors game against the computer, with emojis for fun!  
- **Concepts used**: Functions, loops, dictionaries, random choice, and conditionals.  
- **File**: [`rock_paper_scissors.py`](rock_paper_scissors.py)

---

## 🚀 How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/beginner-python-projects.git
   cd beginner-python-projects
   ```

2. Run any project with:
   ```bash
   python filename.py
   ```
